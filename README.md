# Kimbryle Palma - A11y (Accessibility) Project - Kimmy

A web accessibility project focused on creating inclusive and accessible web experiences.

## 📋 Project Description

This project demonstrates accessibility best practices and implementation for web development. It showcases techniques to ensure websites are usable by everyone, including people with disabilities.

## 🚀 Live Demo

View the project here: [https://kimbryle061-debug.github.io/kimbrylepalma-a11y-Kimmy/](https://kimbryle061-debug.github.io/kimbrylepalma-a11y-Kimmy/)

## 🎯 Features

- Accessible HTML markup
- WCAG compliance
- Keyboard navigation support
- Screen reader friendly
- Semantic HTML structure

## 🛠️ How to Use

1. Clone the repository:
```bash
git clone https://github.com/kimbryle061-debug/kimbrylepalma-a11y-Kimmy.git
```

2. Open `index.html` in your web browser

3. Or visit the live demo: https://kimbryle061-debug.github.io/kimbrylepalma-a11y-Kimmy/

## ♿ Accessibility Features

- Proper heading hierarchy
- Alternative text for images
- Color contrast compliance
- Keyboard navigation
- ARIA labels where needed
